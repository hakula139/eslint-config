All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-14

### Added

- Base flat config with ESLint's recommended rules, strict equality, required braces, unused-binding exceptions, and sorted imports ([#1](https://github.com/hakula139/eslint-config/pull/1)).
- TypeScript flat config with type-aware strict and stylistic rules, PascalCase type names, separate type imports, exhaustive switches, and template interpolation limited to strings and numbers ([#1](https://github.com/hakula139/eslint-config/pull/1), [#3](https://github.com/hakula139/eslint-config/pull/3)).
